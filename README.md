### Work

**[autoduck](https://github.com/krishalivaibhav/autoduck)** — ducks music when someone speaks nearby.
The mic mostly hears the music, not the person, so it cancels the echo first. 32.8 dB measured ERLE.

**[local-multimodal-rag](https://github.com/krishalivaibhav/local-multimodal-rag)** — RAG over technical PDFs where the answers live in tables and figures.
Per-row table chunking, citations back to page and bounding box, fully on-premise.

**[ckyc-auditor](https://github.com/krishalivaibhav/ckyc-auditor)** — five agents screening a bank's customer book against sanctions and adverse media.
The product isn't the alerts it raises, it's the ones it refuses to. Built for Code by Tech Mahindra.
